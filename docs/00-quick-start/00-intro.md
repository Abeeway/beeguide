# Quick Start

This guide helps you get started with Abeeway tracker devices as quickly as possible.

It provides a practical overview of the key topics you need to understand when setting up a device, configuring it for a specific use case, and integrating it with your own application.

Typical onboarding steps are:

1. Learn the main features of your device.  
   See the **Abeeway Devices** section.
2. Turn on your device and connect it to a network.  
   See the **Device Activation** section.  
3. Understand what information the device sends.  
   See the **Payload Format** section.
4. Connect the device to your application server.  
   See the **Application Integration** section.
5. Configure the device for your use case.  
   See the **Device Configuration** section.
6. Explore the firmware in more detail when needed.  
   See the **Firmware Reference Guide** section.
