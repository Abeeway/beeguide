# Quick Start

This guide is intended to help you get started with Abeeway tracker devices as quickly as possible.

It provides a practical overview of the main topics you need to understand when setting up a device, configuring it for a specific use case, and integrating it with your own application.

The typical onboarding steps are:

1. Learn the main features of your device.  
   See the **Trackers** section.
2. Understand what information the device can send.  
   See the **Payload Format** section.
3. Configure the device for your use case.  
   See the **Configuration** section.
4. Connect the device to your application server.  
   See the **Integration** section.
